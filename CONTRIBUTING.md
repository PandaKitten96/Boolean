# Contributing to Boolean

Thank you for your interest in contributing to the Boolean Haskell library!

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```
   git clone https://github.com/<your-username>/Boolean.git
   cd Boolean
   ```
3. Build the project:
   ```
   cabal build
   ```
4. Run the tests to make sure everything passes:
   ```
   cabal test
   ```

## Making Changes

- Keep changes focused and minimal.
- Add or update tests for any new functionality.
- Ensure `cabal build` and `cabal test` pass before submitting.
- Follow the existing code style (Haskell 2010, `-Wall` clean).

## Submitting a Pull Request

1. Push your changes to your fork.
2. Open a pull request against the `master` branch of this repository.
3. Describe what you changed and why.

## Legal

- Ensure contributed code is your own work or is compatible with BSD3 terms.
